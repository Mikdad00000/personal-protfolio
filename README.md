# Mikdad Rahman - Portfolio Website

A modern, responsive portfolio website built with React and Tailwind CSS, showcasing my skills, experience, and projects as a Software Developer.

## Features

- Clean and modern design
- Fully responsive across all devices
- Smooth scrolling navigation
- Interactive UI with hover effects
- Sections for About, Skills, Experience, Projects, and Contact
- Built with React and Tailwind CSS
- Fast and optimized with Vite

## Tech Stack

- **React 18** - UI Framework
- **Tailwind CSS** - Styling
- **Vite** - Build tool
- **React Icons** - Icon library

## Getting Started

### Prerequisites

Make sure you have Node.js (version 16 or higher) installed on your machine.

### Installation

1. Navigate to the project directory:
```bash
cd mikdad-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit: `http://localhost:5173`

### Build for Production

To create a production build:
```bash
npm run build
```

The built files will be in the `dist` folder.

### Preview Production Build

To preview the production build locally:
```bash
npm run preview
```

## Project Structure

```
mikdad-portfolio/
├── src/
│   ├── App.jsx          # Main application component
│   ├── main.jsx         # Application entry point
│   └── index.css        # Global styles with Tailwind
├── index.html           # HTML template
├── package.json         # Dependencies and scripts
├── vite.config.js       # Vite configuration
├── tailwind.config.js   # Tailwind CSS configuration
└── postcss.config.js    # PostCSS configuration
```

## Customization

To customize the portfolio for your own use:

1. Update personal information in `src/App.jsx`
2. Modify colors in `tailwind.config.js`
3. Add or remove sections as needed
4. Update project details and experience

## Deployment

This site can be easily deployed to:

- **Vercel**: `npm install -g vercel && vercel`
- **Netlify**: Drag and drop the `dist` folder
- **GitHub Pages**: Push to GitHub and enable Pages in settings
